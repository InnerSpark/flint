# Getting started

Pick your platform. Every option reads the same tokens.

## Install (web)

```bash
npm install "github:InnerSpark/flint#semver:^1.13.0"
```

The `semver:` range picks up new minor and patch releases on `npm update` and never jumps a major.

## Plain CSS (Astro, EJS, static sites)

```js
import '@innerspark/flint/tokens.css';
```

```css
.card {
  background: var(--color-surface-default);
  color: var(--color-text-default);
  padding: var(--space-16);
  border-radius: var(--radius-card);
}
```

- **Dark mode:** set `data-theme="dark"` on `<html>` or any section. For automatic dark with no toggle, import `tokens.media.css` instead.
- **Density:** set `data-density="compact"` to tighten inset and gap. Control and target sizes never change.

## MUI

```js
import { createFlintTheme } from '@innerspark/flint/mui';

const theme = createFlintTheme({ mode: 'light', density: 'comfortable' });
```

Using MUI next to Tailwind? Put MUI in a cascade layer so its reset does not beat Tailwind's utilities. Wrap the app in `<StyledEngineProvider enableCssLayer>` with `<GlobalStyles styles="@layer theme, base, mui, components, utilities;" />` as its first child.

## shadcn/ui (Tailwind v4)

In your Tailwind entry CSS:

```css
@import "tailwindcss";
@import "@innerspark/flint/tokens.css";
@import "@innerspark/flint/shadcn.css";
```

The bridge points every shadcn variable at a Flint variable and teaches Tailwind's `dark:` variant to follow `data-theme="dark"`. Then restyle each component onto Flint's component tokens. The Components section shows the Flint versions of Button, Input and Checkbox.

## Swift / SwiftUI (iOS 16+, macOS 13+)

Add the package in Xcode with `https://github.com/InnerSpark/flint`, pinned to a version tag.

```swift
import Flint

Text("Awning")
  .flintText(Flint.Typography.headingH2)
  .foregroundStyle(Flint.Colors.textHeading)
  .padding(Flint.Space.s16)
  .frame(minHeight: Flint.Target.touch)
```

- `Flint.Colors` for SwiftUI, `Flint.UIColors` for UIKit APIs such as `UINavigationBarAppearance`.
- `Flint.Component` holds the button, input, checkbox and focus decisions.

## Figma

The Flint library mirrors `tokens.json`. If the two ever disagree, the repo wins and the library gets fixed. For Figma Make, point it at `dist/tokens.css` or `dist/tokens.json`.
